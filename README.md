## 回程、去程、带宽方向，三件事分开看

CN2 GIA 是电信 AS4809 精品网里的高档产品，回程基本都走 59.43 节点，少数没有接入的省份借道 202.97。它白天不丢包，晚高峰的丢包率也压得低，买它图的就是晚上八九点不转圈。

问题在于“三网 CN2 GIA”这句话各家写法不一样。AkkoCloud 圣何塞的线路，第三方测评的说法是三网回程走 CN2 GIA，电信去程也是 GIA 直连；法兰克福和伦敦则是三网回程 GIA，联通、电信去程直连，移动去程走 CMI。去程和回程可能不是同一条线，你从本地发出去的路径和服务器回来的路径要分开看。

验证方法很直接：拿到测试 IP，在本机跑一次 traceroute，看回程是否落在 59.43 段。商家肯把测试 IP 给你，本身就说明线路经得起查。

## 流量是双向计的，别只算一半

AkkoCloud 的流量上传下载都计入额度，500GB 就是上下行加起来 500GB，超出后另外付费。做图床、下载站、视频转发的，先按双向估一遍真实用量，再决定要不要往上一档买。

## 常见问题

**机房在境外，需要备案吗？**
服务器在美国、德国、英国，不涉及国内 ICP 备案流程。但网站本身是否合规、域名怎么解析，还是要按业务所在地的规则来。

**512MB 内存够干什么？**
静态页面、反向代理、定时脚本、监控探针这类够用。带数据库的建站程序、宝塔面板加几个站点，建议直接从 768MB 或 1GB 起。

**CN2 GIA 就不会卡吗？**
不能这么理解。GIA 只保证回程走 59.43 这类精品节点，本地运营商的出口拥塞、跨境链路的临时调整一样会影响速度。买之前要测试 IP 跑 traceroute，买之后按月观察。

**流量超了会怎样？**
按第三方整理的说法，超出额度需要额外付费，具体单价在结算页或工单里确认。跑大流量业务的，选套餐时把双向计费算进去。

**支持哪些付款方式和系统？**
第三方资料提到支持支付宝和 PayPal，系统可选多种 Linux 发行版和 Windows Server。这两项我没在官网页面上逐条核对，下单页看得更准。
